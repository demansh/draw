# Упражнения для рисования

Статическая лента YouTube-роликов с упражнениями для рисования.

Сайт: https://demansh.github.io/draw/

## Как добавить видео

Добавьте запись в массив `VIDEO_LINKS` в файле `videos.js`:

```js
{ url: "https://youtube.com/shorts/XXXXXXXXXXX", tags: ["форма", "объём"] },
```

- `tags` необязательны; можно указать и просто строку-ссылку без тегов.
- Теги можно писать строкой через запятую: `tags: "форма, объём"`.
- Регистр и лишние пробелы не важны: `Форма` и `форма` — один тег.
- Поддерживаются ссылки `youtube.com/shorts/…`, `youtu.be/…` и `youtube.com/watch?v=…`.

## Фильтры

- Вкладки «Все / Shorts / Видео» — тип ролика.
- Теги под вкладками — можно выбрать несколько, показываются ролики со всеми выбранными тегами.
- Фильтры сохраняются в адресе страницы: `?type=shorts&tags=форма,объём`.

## Локальный запуск

```
python3 -m http.server 8080
```

Откройте http://localhost:8080 (через `file://` встроенные видео YouTube не проигрываются).

## Структура

- `videos.js` — список ссылок
- `js/app.js` — точка входа
- `js/feed.js` — лента карточек
- `js/video-catalog.js` — чтение `videos.js` и тегов
- `js/filters.js`, `js/tag-filter.js` — фильтры по типу и тегам
- `js/viewer.js` — полноэкранный просмотр с переключением видео
- `js/youtube-links.js`, `js/youtube-api.js` — разбор ссылок и загрузка YouTube IFrame API

## Обновление сайта

GitHub Pages кэширует файлы на 10 минут. Чтобы телефоны сразу получили новую версию,
перед пушем увеличьте `v=` во всех ссылках в `index.html` (например, `v=4` → `v=5`):

```
sed -i '' 's/?v=4"/?v=5"/g' index.html
```
