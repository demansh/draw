# Упражнения для рисования

Статическая лента YouTube-роликов с упражнениями для рисования.

Сайт: https://demansh.github.io/draw/

## Как добавить видео

Вставьте ссылку строкой в массив `VIDEO_LINKS` в файле `videos.js`.
Поддерживаются ссылки `youtube.com/shorts/…`, `youtu.be/…` и `youtube.com/watch?v=…`.

## Локальный запуск

```
python3 -m http.server 8080
```

Откройте http://localhost:8080 (через `file://` встроенные видео YouTube не проигрываются).

## Структура

- `videos.js` — список ссылок
- `js/app.js` — точка входа
- `js/feed.js` — лента карточек
- `js/viewer.js` — полноэкранный просмотр с переключением видео
- `js/youtube-links.js`, `js/youtube-api.js` — разбор ссылок и загрузка YouTube IFrame API

## Обновление сайта

GitHub Pages кэширует файлы на 10 минут. Чтобы телефоны сразу получили новую версию,
перед пушем увеличьте `v=` во всех ссылках в `index.html` (например, `v=2` → `v=3`):

```
sed -i '' 's/?v=2"/?v=3"/g' index.html
```
